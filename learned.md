# Learned Notes
## Linear Gradient on Navbar Hover
Apply `linear-gradient` on hover for individual elements inside a main container.

## hover:main_element inside-element 
Apply hover on individual inside-elements in a main content

## Carousel Animation
Used to slide items horizontally

## attr() in CSS
attr() fetches attribute values from HTML.
⚠️ Mostly works only with content: in CSS.

# data-* Attributes
Custom attributes used to store extra data in HTML elements.
