# 📌 Project Overview

**NOW! – Productivity App** is a **frontend-only UI concept** that demonstrates how a modern **productivity or SaaS application** could look.

The focus of this project is on:

- Clean and minimal **UI design**
- Responsive **layout structure**
- Organized **web components**
- Using **Bootstrap for responsive layouts**

⚠️ This project is currently a **frontend prototype** and does not include backend functionality.

---

The main goals of building this project were:
